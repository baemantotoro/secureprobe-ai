# Codex Task Management

## 목적

이 디렉터리는 SecureProbe AI 프로젝트의 작업 지침을 WBS ID 기준으로 관리한다.

각 작업은 다음 흐름으로 추적한다.

- 설계
- 구현
- 시험
- 비교
- 보고서

## 폴더 구조

```text
docs/
├── 05_ai_development/
│   ├── codex_tasks/
│   │   ├── README.md
│   │   └── day01/
│   │       └── D01-T01_VALIDATE_BASELINE_DOCS_v0.1.md
│   └── codex_results/
│       └── day01/
│           └── D01-T01_BASELINE_VALIDATION_v0.1.md
- 지침 파일: `D{일자 2자리}-T{작업번호 2자리}_{작업명}_v{버전}.md`
- 검증 결과: 동일 작업 ID를 사용한 결과 문서
- WBS 원문에서 정의된 순서와 의존성을 유지한다.
- 작업 ID를 임의로 추가하거나 변경하지 않는다.

## 상태 관리 원칙

- 지침 파일은 구현 요청 자체이며, 실행 완료를 의미하지 않는다.
- 실제 진행 상태와 결과는 검증 보고서에만 기록한다.
- 요구사항이 변경되면 새 버전을 작성하고 기존 버전을 유지한다.

## 실행 예시

```text
docs/05_ai_development/codex_tasks/day01/D01-T01_VALIDATE_BASELINE_DOCS_v0.1.md를 읽고 실행하라.
## 범위

- 작업 지침과 결과 문서를 분리한다.
- 구현/시험/비교/보고서 흐름을 추적한다.
- 기준 문서의 원문과 WBS 원문을 직접 수정하지 않는다.

## 제한사항

- 이 문서는 코드 개발 또는 보안진단 실행을 대체하지 않는다.
- 누락된 원문은 추정하지 않고, 실제 확인 가능한 자료만 기준으로 한다.
- 이후 작업은 별도 지침 파일을 작성해 진행한다.
