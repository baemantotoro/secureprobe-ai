# D01-T01 — Validate Baseline Docs v0.1

## 1. 목적

Day 1 기준 문서를 검증하고, 실제 저장소에 존재하는 문서와 WBS/기준 문서의 관계를 확인한다.

이 작업은 코드 구현이 아니라 문서 기준 검증이며, 이후 Python 개발환경 구성 등 다음 작업이 진행될 수 있는지를 판단하는 기준 역할을 한다.

## 2. 작업 ID와 근거

- WBS 기준: Day 1, Task 01
- 작업명: 기준 문서 검증
- 의존성: 없음
- 우선순위: P0

## 3. 검증 대상

다음 기준 문서가 저장소에 존재하고, 서로의 경로와 목적이 일치하는지 확인한다.

```text
docs/00_context/PROJECT_CONTEXT_v0.1.md
docs/01_architecture/ARCHITECTURE_v0.1.md
docs/01_architecture/AGENT_FLOW_v0.1.md
docs/02_spec/DATA_SCHEMA_v0.1.md
docs/03_wbs/WBS_20DAYS_v0.1.md
```

## 4. 수행 절차

1. 저장소에서 문서 파일 존재 여부를 확인한다.
2. 문서 경로가 WBS 기준 문서와 일치하는지 검증한다.
3. AGENTS.md와 저장소 규칙을 준수하는지 확인한다.
4. 누락된 원문이 있는 경우, 추정 없이 실제 존재 여부만 기록한다.
5. 결과를 `docs/05_ai_development/codex_results/day01/D01-T01_BASELINE_VALIDATION_v0.1.md`에 저장한다.

## 5. 확인 항목

- 기준 문서 5개가 실제로 존재하는가
- 문서 권한, 이름, 경로가 일치하는가
- WBS의 Day 1 기준 문서 목록과 실제 파일 구성이 일치하는가
- 실제 구현 전 필요한 문서가 모두 준비되었는가
- 누락 내용이 있다면 이유와 제한을 명시하는가

## 6. 비고

이 작업은 실제 구현이나 환경 설정을 수행하지 않는다.

정확한 기준 문서가 확인되지 않은 상태에서는 다음 작업의 상세 요구사항을 추정해 보충하지 않는다.
