# Ground Truth

Ground Truth는 SecureBoard Lab에 의도적으로 삽입된 취약점의 정답 정보를 관리하는 영역이다.

현재 단계에서는 실제 취약점 상세 내용을 작성하지 않고, 향후 관리 원칙과 항목 구조를 정의한다.

## 관리 항목 예정

- ID
- 취약점명
- 발생 위치
- 취약 코드
- 발생 원인
- 예상 진단방법
- Evidence 기준
- 수정방법
- Re-Test 기준

## 향후 예정 취약점 예시

- GT-01 SQL Injection
- GT-02 Reflected XSS
- GT-03 Stored XSS
- GT-04 Broken Access Control / IDOR
- GT-05 CSRF
- GT-06 File Upload Validation
- GT-07 Path Traversal
- GT-08 Security Header
- GT-09 Cookie / Session Configuration
- GT-10 Information Exposure

Ground Truth는 실제 진단 결과와 비교 평가의 기준이 된다.
